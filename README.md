# Typing Test

A simple typing test for POSIX-compatible systems.

## Requirements

- A POSIX-compatible operating system, such as Linux or macOS.
- A C compiler and `make`.

**Note:** This program is designed for POSIX systems and does not run natively on Windows. Windows users can run it through WSL (Windows Subsystem for Linux) or another POSIX-compatible environment.

## Clone

Clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd <repository-directory>
```

Replace `<repository-url>` with your Git repository URL and `<repository-directory>` with the cloned folder name.

## Path

The typing test is located **beside `v1`**, not inside it.

## Build

```bash
make
```

## Run

```bash
./typing-test
```

## Clean

```bash
make clean
```

Use `make clean` to clear the build files.
