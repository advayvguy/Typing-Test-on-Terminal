# Typing Test

A simple typing test.

## Clone

Clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd <repository-directory>
```

Replace `<repository-url>` with your Git repository URL and `<repository-directory>` with the cloned folder name.

## Path

The typing test is located **beside `v1`**, not inside it.

## Build

```bash
make
```

## Run

```bash
./typing-test
```

## Clean

```bash
make clean
```

Use `make clean` to clear the build files.
